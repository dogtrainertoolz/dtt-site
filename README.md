# Dog Trainer Toolz (dtt-site)

Static site for dogtrainertoolz.com, served as a Cloudflare Worker (static assets). Same setup as dyd-site / diw-site.

## Deploy (its own GitHub + Cloudflare accounts, so it can be sold complete)
1. GitHub Desktop signed in as `dogtrainerz` → clone the empty repo into a NEW folder in Documents\GitHub → copy everything from this folder into it → commit → publish.
2. Cloudflare (dogtrainerz account) → Workers & Pages → Create → Import from GitHub → this repo.
   Build command: *(leave empty)*. Deploy command: `npx wrangler deploy`. `public/` is already built.
3. Add dogtrainertoolz.com to Cloudflare, switch nameservers at the registrar, delete the old A/AAAA/CNAME records,
   then Workers → dtt-site → Settings → Domains & Routes → add `dogtrainertoolz.com` and `www.dogtrainertoolz.com`.
4. Cloudflare Email Routing: forward `hello@dogtrainertoolz.com` (the site's contact address) to dogtrainerz@gmail.com.

## Editing
- Settings, topics and the Amazon tag (`dogtrainerz2026-20`): `site.json`.
- Guides: `content/guides/*.md` (`pillar:` = topic slug). Amazon links: `[text](amzn:search words)`.
- Free tools: `content/tools/*.html` (front matter + HTML/JS, then Markdown notes after the script).
- Gear page: `content/picks.json`. Photos: `content/images.json` + `python3 scripts/get_images.py`.
- Rebuild: `python3 scripts/build.py` (needs `pip install markdown pillow`), then commit `public/`.

## Redirects
All 848 old scraped video posts plus pages and categories 301 to the closest new guide (keyword-matched).
Generated by `scripts/make_redirects.py` into `redirects.txt`, copied to `public/_redirects` on build.
